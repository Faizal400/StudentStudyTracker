# Smart Study Tracker
> A Django web application that helps students track study time by subject/module/submodule, run a focus timer and view time-based categorised insights.
---
### What this application has to offer so far
- basic auth (login/register/logout)
- focus timer that saves sessions (only for subjects, not for modules/sub-modules yet)
- CRUD for subjects/modules/submodules
- insights page (total hours, last 7 days, top subjects) - again, not for module/submodules yet.
---
*All in which will be improved upon / added on overtime* 😊


---
## What you can do right now
- Create subjects, modules, submodules
- Start/stop a focus timer and save a study session
- Insights: total study time, last 7 days, top subjects by time
- Sidebar shows `[Subject -> Modules -> Sub-Modules]` hierarchy
